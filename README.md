# Fairway

A golf companion: a web app at [fairway.appelent.nl](https://fairway.appelent.nl) and an
Expo mobile app (`apps/mobile`), sharing a Convex backend.

```bash
pnpm install
pnpm env:apply local --only file   # writes the .env.local files from Infisical
pnpm dev:watch                     # Convex dev + Vite on port 3000
```

Commands, architecture and deploys: [AGENTS.md](AGENTS.md). Coding rules:
[CODING_STANDARDS.md](CODING_STANDARDS.md). Runbooks: [docs/runbooks](docs/runbooks).
